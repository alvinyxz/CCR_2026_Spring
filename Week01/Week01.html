1.1.1. R - Basic Setup

Dr. Josephine Lukito has a great installation guide for R and RStudio. Please follow her instructions to set up your environment: https://jolukito.quarto.pub/j381m-textbook/01-installation.html

  1. Install R from CRAN
  2. Install RStudio from RStudio
  3. Creating a new .R file in RStudio:
    • Open RStudio
    • Click on "File" in the top left corner
    • Select "New File" and then "R Script"

  4. Write this the following script, and hit "Ctrl + Enter" or clicking the "Run" button in RStudio.
install.packages("praise")
  1. Load the package in RStudio:
library("praise")
  1. Run the following code in RStudio and get a random praise message:
praise()
  1. Save the file as praise.R locally.
  2. Open praise.R again, make sure .R is associated with RStudio from now on. Run the code again to get a new random praise message.

1.1.3. R - Basic Commands 2

  1. Open RStudio and create a new R script file.
  2. First, we will install the datasets package:
install.packages("datasets")
# Most of the time, you do not need to install it, because it is already installed in RStudio
  1. Load the package:
library(datasets)
  1. Load the mtcars dataset:
data(mtcars)
  1. View the first few rows of the dataset. Remember, while you can type it in the console to run it, I recommend you to always type this in the script file, so that you can save it again later.
head(mtcars)
head(mtcars, n = 10)
tail(mtcars)
summary(mtcars)
  1. Interpret what each of the line means
  2. We also need to know what class the object is. You can do that by:
class(mtcars) # The `mtcars` dataset is a data frame, which is a table-like structure in R.
class(mtcars$mpg) # While the `mpg` column is numeric, which means it contains numbers.
  1. You can also check the structure of the dataset using the following code. This will give you information about the columns, their types, and the first few values in each column.
str(mtcars)
  1. This is important because we need to know what kind of data we are dealing with. For example, if you want to do a regression analysis, you need to know if the variables are numeric or categorical. Sometimes, the class of the variable is not what you expect. For example, if you have a number variable, but it could be wrongfully stored as a character string:
number_variable <- "10"
class(number_variable)
  1. Instead, you should use "as." commands to change it to the class that you need:
number_variable <- as.numeric(number_variable)
class(number_variable)
number_variable <- as.character(number_variable)
class(number_variable)
  1. Further, you can type out these commands to visually learn the differences:
# Create a character variable
4
# It will show up as:
# [1] 4
# But if you type:
as.character(4)
# It will show up as:
# [1] "4"
# But if you type:
as.numeric("four")
# It will show up as NA and gives a warning message: Warning: NAs introduced by coercion
  1. Save the file as basic_commands_2.R locally.
  2. For more information on data structures in R, see Jo's tutorial: https://jolukito.quarto.pub/j381m-textbook/05-structures.html

1.1.4. R - Common Commands

  1. Open RStudio and create a new R script file.
  2. These few commands are widely used in R for logistic reasons:
# Create a vector
my_vector <- c(1, 2, 3, 4, 5)
# Create a matrix (only numbers)
my_matrix <- matrix(1:9, nrow = 3)
# Create a data frame (basically a table)
my_data_frame <- data.frame(Name = c("Alice", "Bob"), Age = c(25, 30))
View(my_data_frame)
# Clean working environment
rm(list = ls())
# Get working directory
getwd()
# It might show up a path like on PC like "C:/Users/YourName/Documents" or on Mac like "~/Documents"
# Set working directory
setwd("path/to/your/directory")
# You can set it to your own path, like "C:/Users/YourName/Documents/" or on your desktop
# Reading in a CSV file
my_data <- read.csv("C:/Users/YourName/Documents/Week01.csv")
# But if you have already set the working directory and the file is in that directory, you can just do:
my_data <- read.csv("Week01.csv")
# You can have a look at the data
head(my_data)
head(my_data, n = 1)
# You can print out the column names of the data
colnames(my_data) # or simply names(my_data)
# Or you can use the View function to open it in a new tab
View(my_data)
# You can look at one specific variable as well
head(my_data$favorites)
# Look at the mean of a variable
mean(my_data$favorites)
# Look at the median of a variable
median(my_data$favorites)
# Look at the standard deviation of a variable
sd(my_data$favorites)
# Look at the variance of a variable
var(my_data$favorites)
# Look at the maximum of a variable
max(my_data$favorites)
# Look at the minimum of a variable
min(my_data$favorites)
# Look at the correlation of two variables
cor(my_data$favorites, my_data$retweets)
cor.test(my_data$favorites, my_data$retweets)
# Plot it
plot(my_data$favorites, my_data$retweets)
# You can run a regression with it too
lm_model <- lm(my_data$retweets ~ my_data$favorites)
# Or you can use the formula directly
lm_model <- lm(retweets ~ favorites, data = my_data)
summary(lm_model)
# You can use table() to look at the frequency of a variable
table(my_data$Party)
table(my_data$chamber)
table(my_data$author)
  1. Some very common keyboard shortcuts in RStudio:
    • Ctrl + Enter: Run the current line or selection
    • Ctrl + Shift + C: Comment or uncomment the current line or selection
    • Ctrl + Shift + M: Insert the pipe operator (%>%) (ignore for now, but we might talk about later)
  2. One common keyboard shortcut to copy a file's path:
    • On Mac: Command + Option + C
    • On Windows: Hold down Shift, then right-click the file

1.2. Python

There are two ways to run Python code: through an IDE (Integrated Development Environment) (like RStudio) or, more easily nowadays, through Google Colab.

1.2.1. Python - Google Colab

  1. Go to https://colab.research.google.com/
  2. Click on "New Notebook" in the bottom right corner
  3. It will open a new tab with a blank notebook
  4. In the first cell, type:
print("Hello, world!")
  1. Run the cell by clicking the “Run” button or pressing Shift + Enter
  2. Since you are using Google Colab, you can also use Markdown (a text-based formatting syntax) to write notes. To do this, create a new cell and change the cell type from Code to Text from the dropdown menu. Type:
# This is a header
## This is a subheader
  1. Run the cell to see the formatted text
  2. Since Python doesn't have an equivalent of R's praise package, we will use the random package to generate a random praise. Type:
import random
compliments = [
 "You're doing amazing!",
 "That was a great cell!",
 "Nice job!",
 "Python suits you.",
 "You're not just coding, you're crafting!"
 ]
 print(random.choice(compliments))
  1. Run the cell by clicking the “Run” button or pressing Shift + Enter

1.2.4. Python - Basic Commands 2

  1. Regardless of whether you are using Google Colab or JupyterLab, create a new notebook and name it basic_commands_2.ipynb
  2. In the first cell, import pandas and numpy (panda is the most widely used package for data analysis in Python, and numpy is the most widely used package for numerical analysis):
import pandas as pd
import numpy as np
  1. In the second cell, create a DataFrame using a built-in dataset:
from sklearn.datasets import load_iris
iris = load_iris(as_frame=True)
df = iris.frame
  1. In the third cell, explore the dataset:
df
  1. In the fourth cell, view the first few rows of the dataset:
df.head()
  1. In the fifth cell, view the last few rows of the dataset:
df.tail()
  1. In the sixth cell, view the summary of the dataset:
df.describe()
  1. In the seventh cell, view the structure of the dataset:
df.info()
  1. In the eighth cell, view the column names of the dataset:
df.columns
  1. At this point, you should see that in Python, the first row is indexed as 0, and the last row is indexed as 149. So, to get the first row, you can do:
df.iloc[0]
  1. To get the last row, you can do:
df.iloc[-1]
  1. To get the first 10 rows, you can do:
df.iloc[:10]
  1. To get the first column, you can do:
df.iloc[:, 0]
  1. To get the last column, you can do:
df.iloc[:, -1]
  1. Or, if you know the name of the column, you can do:
df['sepal length (cm)']

1.2.5. Python - Common Commands

  1. Regardless of whether you are using Google Colab or JupyterLab, create a new notebook and name it common_commands.ipynb
  2. In the first cell, import pandas and numpy:
import pandas as pd
import numpy as np
  1. In the second cell, get/change working directory:
# Check current working directory
import os
os.getcwd()
# Change working directory (optional)
# os.chdir("/your/path/here")
  1. In the third cell, create a list:
# Create a list
my_list = [1, 2, 3, 4, 5]
print(my_list)
  1. In the fourth cell, create a dictionary:
# Create a dictionary and convert to a DataFrame
my_data_frame = pd.DataFrame({
"Name": ["Alice", "Bob"],
"Age": [25, 30]
})
print(my_data_frame)
  1. In the fifth cell, read in a CSV file:
data = pd.read_csv("Week01.csv")
# View data
data
  1. In the sixth cell, view the first few rows of the data:
data.head()
  1. In the seventh cell, view the last few rows of the data:
data.tail()
  1. In the eighth cell, view the column names of the data:
data.columns
  1. In the ninth cell, view the summary of the data:
data.describe()
  1. In the tenth cell, view the first column of the data:
data.iloc[:, 0]
  1. In the eleventh cell, view the first row of the data:
data.iloc[0]
  1. In the twelfth cell, view the last column of the data:
data.iloc[:, -1]
  1. In the thirteenth cell, view the first 10 rows of the data:
data.iloc[:10]
  1. In the fourteenth cell, once you know which column to look into, you can describe the data:
data['favorites'].describe()
  1. In the fifteenth cell, you can try different functions:
data["favorites"].mean()
data["favorites"].median()
data["favorites"].std()
data["favorites"].var()
data["favorites"].max()
data["favorites"].min()
  1. In the sixteenth cell, you can also look at the correlation of two variables:
data[['favorites', 'retweets']].corr()
# The two brackets "[[" indicate which columns to draw
  1. You can also use a more logical approach:
# you pick out favorites first, and then calculate the correlation with retweets
data["favorites"].corr(data["retweets"])
  1. In Python, we usually use matplotlib to plot the data:
# Plotting
import matplotlib.pyplot as plt

plt.scatter(data["favorites"], data["retweets"])
plt.xlabel("Favorites")
plt.ylabel("Retweets")
plt.title("Scatterplot of Favorites vs Retweets")
plt.show()
  1. Run a linear regression with statsmodels.api:
import statsmodels.api as sm
X = data["favorites"]
y = data["retweets"]
X = sm.add_constant(X)
# statsmodels.OLS() does not automatically add a constant term
model = sm.OLS(y, X).fit()
print(model.summary())

1.3. Learn how to debug your code with ChatGPT

  1. Open ChatGPT (I have it installed on my Mac) and start a new conversation
  2. Copy and paste your code into the chat
  3. Describe the issue you're facing
  4. Ask for help with debugging

To practice, I have two scripts with errors, stored in the current folder called debugging_example.R and debugging_example.py.

  1. Download the two files.
  2. Run them in RStudio and JupyterLab
  3. You should see some errors
  4. Copy and paste the code into ChatGPT and ask it to debug the code
  5. ChatGPT will help you identify the errors and suggest fixes
  6. Apply the fixes to your code and run it again
  7. You should see the output without any errors
  8. You can also use ChatGPT to explain the code to you, so that you can understand it better.

1.4. Focus on R and One More Add-On

We will focus on R for the rest of the workshop. However, if you are interested in Python, you can use it as well. The code is similar, and you can easily convert it from R to Python or vice versa (using ChatGPT).

One more add-on I highly recommend in R Studio is the GitHub Copilot. It is a paid service, but free for students. You can sign up for it here:

This is a great tool to help you write code faster and more efficiently. It can also help you debug your code and suggest improvements. You can use it in RStudio, JupyterLab, and other IDEs.

To enable it in RStudio, go to Tools > Global Options > Copilot and check the box to enable it. You can see a quick tutorial here: https://www.youtube.com/watch?v=YZdp6To__1g
